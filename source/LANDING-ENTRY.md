# QUERY PANEL PLANNER

Panel planner for Steelcase Answer systems, Thin and Oval trim (renamed from ANSWER on September 26, 2026). Draw runs or place typicals, right-click to add worksurfaces and pedestals, set tiles, windows, power and frameless glass per panel, and get the full spec with exact style numbers, then shop work orders, pick lists and installer sheets from the same job file. Exports SIF for CAP and dealer ordering.

Every reference to the Answer Specification Guide opens that page of the PDF.
